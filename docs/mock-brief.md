# モック共通指示書（3案共通・この中身は一字一句変えない）

目的: 「銘柄分析 兼 勉強ツール」（仮称 KABU LAB）のデザイン案を比較するための静的モック。
3案は **同じ中身** を別の見た目・レイアウトで見せる。利用者は投資初心者・PC専用（横幅1280〜1920px）。
ツールの思想: AIは売買の正解を当てる装置ではない。複数シナリオと根拠を見せて「相場観」を養う分析・学習ツール。
だから「買い推奨」「売り推奨」の断定表示は置かない。シナリオ・根拠・崩れる条件・用語解説を主役にする。
利用者の要望: **グラフ・図解を多く**。文章だけのブロックを作らず、数字は必ず図に変換する。

### ⑨ 学びノート（用語チップ＋一言）
- PER: 株価が1年分の利益の何倍か
- 信用倍率: 借金して買っている株数 ÷ 空売りの株数。高いと将来の売り圧力
- 乖離率: 移動平均線からどれだけ離れているか。±10%超は過熱の目安
今回の気づき: 「PER 27倍は割高ではなく、成長を先に織り込んだ値段。成長が鈍ると下がりやすい」

## 技術制約（3案共通）
- 1案=1ファイルの自己完結HTML（CSS/JSはインライン）。外部依存は Google Fonts の <link> のみ可。チャートライブラリ・画像ファイルは使わず、図はすべてインラインSVGかCSSで描く。
- 株価データは mocks/data/6501_daily.json の内容をHTML内にJSONとして埋め込む（fetchしない。file:// で開いて動くこと）。
- 文字は日本語。数字は等幅で桁を揃える。上昇＝赤系・下落＝緑/青系の日本式配色に合わせる必要はないが、上げ下げの色は凡例で明示する。
- 1440×900 で初期表示が破綻しないこと。横スクロール禁止。
- 見た目の派手さより「読めること」。本文コントラスト比 4.5:1 以上、最小文字 12px。
